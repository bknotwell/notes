Emacs has an [[https://www.gnu.org/software/emacs/manual/html_node/emacs/Indirect-Buffers.html][Indirect Buffer]] capability that makes it so you can have
the same file opened with a cursor opened in different places.

Relevant functions:
+ =clone-indirect-buffer=
+ =clone-indirect-buffer-other-window=
+ =make-indirect-buffer=
