* Background
The original Unix text editor is [[https://en.wikipedia.org/wiki/Ed_(software)][ed]].  It's worth knowing even if you
use it infrequently.  Start with the [[https://man.freebsd.org/cgi/man.cgi?query=ed&sektion=1&format=html][manpage]] or  Michael Lucas'
[[https://www.amazon.com/Ed-Mastery-Standard-Unix-Editor/dp/1642350036][book.]] 

* Examples
** Insert data starting on the second line
#+begin_src sh
# insert new rows in a CSV file after the header
ed -s<<EOF
E t.csv
2i
100,101,102
103,104,105
.
wq
EOF
# 
#+end_src
