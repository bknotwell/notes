Install the [[https://github.com/paws-r/paws][paws]] package and run the following code to download key
information from the bucket and store it in a file that can be reloaded:

#+begin_src R :exports code
  require(paws)
  s3 <- paws::s3) 
  data <- paginate(s3$list_objects(Bucket = 'my-bucket-name'))
  rm(s3)
  save.image(file = 'my-bucket-name-ls.RData')
#+end_src
