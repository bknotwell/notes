Editing tables can be made easier with the following tips:

+ { Ctrl-} } (dis | en)ables row and column addressing.
+ { Ctrl-{ } (dis | en)ables formula debugging.
+ { Ctrl-c = } input the formula for a column.
+ { Ctrl-c ' } edit table formulas in a separate buffer with
  highlighting.

Use the menubar if you cannot remember the keybindings.
