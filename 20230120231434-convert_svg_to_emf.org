#+title: Convert svg to emf
#+OPTIONS: ^:nil author:nil html-postamble:nil
#+SETUPFILE: ./latexcss.theme

[[https://inkscape.org/][Inkscape]] can be used to convert svg files to emf files with a command
like the following:

=/Applications/Inkscape.app/Contents/MacOS/inkscape td.svg
--export-filename td.emf=

*NB:* command was tested with Inkscape v1.2.
