Generate asymptotic graphs.

#+begin_src  R  :session R-asymptote :exports both :results output graphics file :file simple-asymptote.svg
plot(sapply(1:60, function(x) x/(x+1)), main='x/x+1', type='l', xaxt='n', xlab='', ylab='')
#+end_src

#+begin_src  R  :session R-asymptote :exports both :results output graphics file :file simple-asymptote-2.svg
plot(sapply(1:60, function(x) 1/x), main='1/x', type='l',  xaxt='n', xlab='', ylab='')
#+end_src

Not an asymptote but equally fun:

#+begin_src  R  :session R-asymptote :exports both :results output graphics file :file simple-spiral-1.svg
plot(sapply(seq(0,10, len=750), function(x) complex(modulus=sqrt(x), argument = 2*pi*x)),
        type='l', main='Spiral ',  xaxt='n', yaxt='n')
#+end_src
