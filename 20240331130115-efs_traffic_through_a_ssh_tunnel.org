An EFS filesystem can be mounted to a local machine in the following
way:

1. Create a VM jump box that has [[id:999317F5-4E06-4A80-A6AB-088445E9EA7E][Script to edit sshd_config to
   /AllowTcpForwarding/]] enabled.
2. Setup an SSH tunnel: =ssh -fN -L 2049:fs-XXXXXXXXXX.efs.XX-XXXX-X.amazonaws.com:2049 ec2-usr@ec2-XXX-XXX-XXX-XX.XX-XXXX-X.compute.amazonaws.com=
3. Mount the filesystem: =sudo mount -t nfs -o rw,vers=4,rwsize=1048567,retrans=2 localhost:/ /efs=

*NB:* the jump box can mount the filesystem while still encrypting
tunneled traffic for multiple users.
