The header block for graphics output can be tricky.  For future
reference, an example follows:

#+begin_example
#+begin_src ... :exports results :results output graphics file :file "filename.jpg"
#+end_example

If you want to switch the image type dynamically, you need some Emacs
lisp like the following:
 #+begin_example
(concat "filename." (if (equal org-export-current-backend 'html) "svg" "pdf"))
 #+end_example

and languages supporting graphics generation will do the right thing.
