Setting up a Chisel app repository:

1. Login to [[https://chiselapp.com/][chiselapp.com]] and create a repo.
2. Setup your local repo (see [[id:6B7B3019-5399-4665-B6B5-3DABAA1BD944][Repo creation]]) to point to your new
  chisel app repo.
3. Set the fossil user default: =fossil user default name=
4. Do your commit as that user.
4. Do a push like the following: `fossil push
   https://myuser@chiselapp.com/user/myuser/repository/myrepo`.

Make sure to have the system remember your password.
