You can display the [[https://tableplus.com/blog/2018/08/postgresql-how-to-show-stored-procedure.html][code]] from a running stored procedure in the
following way:

#+begin_src sh
SELECT prosrc FROM pg_proc WHERES proname = 'function_name';
#+end_src
