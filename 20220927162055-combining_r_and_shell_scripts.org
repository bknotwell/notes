If you have a shell script creating data that's fed to [[https://www.r-project.org/][R]], you might
want to combine the two:

#+begin_src sh :exports code
# might be simpler than loading SQLite support in R
sqlite3 -csv -header $1 'SELECT * from logs' > $$.csv

cat > $$.R <<EOF

data <- read.csv('$$.csv')
cat("Message length summary")
summary(data\$msglen)

cat("Message length distribution")
stem(data\$msglen)
EOF

rm $$.csv
#+end_src
