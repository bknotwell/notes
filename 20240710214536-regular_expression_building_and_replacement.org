Text replacement via regexp in a buffer can be easily [[https://karthinks.com/software/bridging-islands-in-emacs-1][performed]] by the following method:

1. Open ={re-builder}= and build your regexp.
2. Copy it to the kill ring ={C-c C-w}=
3. Quit =re-builder= ={C-c C-q}=
4. Run ={query-replace-regexp}=
5. Type in the replace string and hit ={RET}=.
