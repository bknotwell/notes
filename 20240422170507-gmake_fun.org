Some interesting /gmake/ snippets.

Find the /README.m4/ and /_sidebar.m4/ files and remove the ones in the
current directory:
#+begin_example
M4SRCS=$(filter=out ./README.m4 ./_sidebar.m4, $(shell find . -name 'README.m4' -o '_sidebar.m4'))
#+end_example

Swap file suffixes (/m4/ to /md)/:
#+begin_example
$(M4SRCS:.m4=.md)
#+end_example
