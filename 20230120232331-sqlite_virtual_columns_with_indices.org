SQLite supports [[https://www.sqlite.org/gencol.html][generated columns]] which can be combined with indexes
to significantly increase JSON query performance.

Methodology:
1. Create the table with the generated column using the =json_extract=
   function.
2. Create an index on the generated column's name.

*NB:* this method only works when the generated column is added at
creation time.
