It's easy to parse HTML files using [[https://www.lua.org][Lua]] [[https://pandoc.org/lua-filters.html#introduction][filters]] in [[https://pandoc.org][pandoc]].  The
following script extracts all links starting with
[[https://docs.google.com]] out of a parsed file:

#+begin_src
-- this was run against an exported google docs spreadsheet
-- 
-- printing out the link target for a match and return nothing
-- so the element's deleted
function Link(lnk)
  if string.sub(lnk.target, 1, 23) == "https://docs.google.com"
  then
    print(lnk.target)
  end
  return {}
end

-- drop all other elements
function Div(div) return {} end
function Image(img) return {} end
#+end_src

See the [[https://pandoc.org/lua-filters.html#module-pandoc][module documentation]] for information on the available object
types.
