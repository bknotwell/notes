SQLite has multiple search methods available.  The latest one--[[https://www.sqlite.org/fts5.html][v5]]--can
be setup in the following way:

#+begin_src sh
CREATE VIRTUAL TABLE notes USING FTS5(title, body, tokenize=porter);
#+end_src

The /porter/ setting turns on fuzzier matches.
