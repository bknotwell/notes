Loans can be amortized with the following formula:

$A = P * ((i(1+i)^n) / ((1+i)^n - 1))$

In R:

#+begin_src R
calcamortization <- function(P, i, n) P * ((i * ((1 + i)^n)) / (((1 + i)^n) - 1))
#+end_src

Let's do it numerically in R:

#+begin_src R :session A-numeric

numericamortization <- function(P, N, i, A) {
    NPP <- Reduce(function(NPrime, ignored) (NPrime * (1 + i)) - A, 1:N, P) 
    
    if(NPP < 5)
        A
    else
        numericamortization(P, N, i, A + 1)
}
#+end_src
