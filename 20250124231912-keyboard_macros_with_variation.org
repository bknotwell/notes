* Defining a variant macro
Creating emacs macros with [[https://www.gnu.org/software/emacs/manual/html_node/emacs/Keyboard-Macro-Query.html][variation]]:

1. Start creating your macro.
2. {C-x q} when you need to do a custom input.
3. Stop creating the macro.

* Executing a variant macro

1. Start executing your macro.
2. {C-r} when the macro prompts you for a recursive edit.
3. Do your custom edits and run {C-M-c} to return control back to the
   original macro.

These can be profitably combined with snippets to create complex text
generation workflows.
