Some example code that creates a temporary buffer, fills the lines and
copies data to the clipboard:

#+begin_src emacs-lisp
  (defun get-string ()
     (interactive)
     (set-buffer (get-buffer-create "my-temporary-buf"))
     (insert "a string that goes into the buffer as test data")
     (fill-region (point-min) (point-max))
     (clipboard-kill-region (point-min) (point-max))
     (kill-buffer))
#+end_src
