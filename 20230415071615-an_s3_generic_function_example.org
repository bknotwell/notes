R has several object-oriented methods.  It's most basic is the [[http://adv-r.had.co.nz/S3.html][S3]]
method that uses [[https://en.wikipedia.org/wiki/Generic_function][generic functions.]]  An example:

#+NAME: genericfunction
#+begin_src R  :exports both  :results output
  jump <- function(x, ...) UseMethod('jump')
  jump.human <- function(obj) '1 meter'
  jump.flea <- function(obj) '.005 meter'
  factory <- function(species) {
    res <- list(name=species)
    class(res) <- res['name']
    return(res)
  }

  cat(jump(factory('flea')),'\n')
  cat(jump(factory('human')),'\n')

  # this won't show up as jump.frog is unimplemented
  cat(jump(factory('frog')),'\n')
#+end_src

Output:
#+RESULTS: genericfunction

To see an object's class: src_r[:exports code]{attributes(objectinstance)$class}.
