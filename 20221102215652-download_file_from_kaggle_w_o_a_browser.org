Using the webUI, setup an API key and store it in
=~/.kaggle/kaggle.json= (*NB:* this specific location is only necessary if
you want to use their CLI).

To install their CLI: =pip3 install kaggle= and you can use it.  If
you'd prefer to make calls directly, you'll do a command like the
following:

#+begin_src sh :tangle kaggle-download.sh :var filename=".kaggle/kaggle.json" :var user="piterfm" :var dataset="2022-ukraine-russian-war"
  auth=$(jq -rj '.username, ":", .key' $HOME/$filename | openssl enc -base64)
  ENDPOINT=https://www.kaggle.com/api/v1/datasets/download
  redir=$(curl -H "Authorization: Basic $auth" $ENDPOINT/$user/$dataset --write-out "%{redirect_url}")
  curl $redir > $$.zip
  unzip $$.zip
  rm $$.zip
#+end_src
