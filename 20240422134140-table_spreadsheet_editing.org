Editing per cell table formulas can be done far more easily by doing
them in the formula editor:

1. Hit {Ctrl c '} to open the editor.
2. Use normal editing to update individual cells.
3. Hit {Ctrl c c} to exit the table editor back to org mode.
4. Hit {Ctrl c c} again to recalculate the table's changes.
