After upgrading node (might be FreeBSD-specific), shiny might have
trouble starting because it can't find the /POSIX/ module:

#+begin_example
Error:  Cannot find module '../../build/Release/posix'
#+end_example

Remedy this by linking the /posix/build/Release/ directory to the
/Release/ in shiny server's top-level /build/ directory:

#+begin_src  sh
cd  /usr/local/shiny-server/build
ln -s ../node_modules/posix/build/Release Release
#+end_src

It might be necessary to rebuild the /POSIX/ module using /gmake/ from the
/node_modules/posix/build/ directory.
