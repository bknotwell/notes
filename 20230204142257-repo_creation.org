#+title: Repo creation
#+OPTIONS: ^:nil author:nil html-postamble:nil
#+SETUPFILE: ./latexcss.theme

Do the following to create a fossil repo:

1. =fossil init [-A username] reponame.fossil=
2. =mkdir reponame; cd reponame=
3. =fossil open ../reponame.fossil=

*NB:* the =-A username= is crucial if you want to commit with a different
(e.g. [[https://chiselapp.com/][chiselapp]]) username.
