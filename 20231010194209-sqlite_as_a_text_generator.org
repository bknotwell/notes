#+title: SQLite as a text generator
#+OPTIONS: ^:nil author:nil html-postamble:nil

SQLite can be to generate complex text output by setting the query
separator to a =''= character on the command-line.  Likewise, the
[[https://www.sqlite.org/lang_corefunc.html#replace][replace]] and [[https://www.sqlite.org/lang_corefunc.html#substr][substr]] functions can be used to transform data.

#+begin_src sh
sqlite3 -separator '' t.db<<EOF
   SELECT 'Filename: ', REPLACE(name, '.exe', '.c'), '  ::  Function: ',
          SUBSTR(functionname, 4);
      FROM table;
EOF
#+end_src
