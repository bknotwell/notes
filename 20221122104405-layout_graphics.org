Setting up graph layout can be down with =par(mfrow=c(n, nprime))= or
the [[https://www.rdocumentation.org/packages/graphics/versions/3.6.2/topics/layout][layout]] function:

#+begin_src R :exports both :results output graphics file :file layout.svg
layout(matrix(c(1,1,1,2,2,2,3,3,4,4,5,5),nrow=2,byrow=TRUE))

hist(rnorm(100, 110, 11))

hist(rnorm(100, 330, 33))

hist(rnorm(100, 550, 55))
