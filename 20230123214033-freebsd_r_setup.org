Setting up R on FreeBSD requires a single command: =pkg install R=

*NB:* R is in the =math/R= area of the ports tree not =lang=.

Depending on when you install, you may need to do some combination of
=pkg update= and =pkg upgrade= to get a newer /icu/ version that avoids the
following error:

=ld-elf.so.1: Shared object "libicuuc.so.72" not found, required by "libR.so.4"=
